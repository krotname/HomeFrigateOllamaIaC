# Наблюдение за положением шлагбаума

`ocr.frigate_barrier` публикует `barrier_state`: 0 — «Неопознано», 1 — «Закрыто», 2 — «Открыто». Это наблюдение камеры; модуль не отправляет команды управления.

Для фиксированной камеры поддерживается классификатор `hog-linear`. В локальной конфигурации укажите `classifier: "hog-linear"` и абсолютный `model_path` внутри контейнера. Модель — JSON с двумя линейными SVM, описанием камеры, разрешения, областей `pose` и `arm`, версией признаков и стабильной SemVer-версией. Модель и размеченные кадры хранятся вне Git; pickle не используется. Загрузка ограничена 2 MiB, проверяются размеры и конечность коэффициентов. Повреждённая или несовместимая модель даёт «Неопознано».

По умолчанию продолжает работать прежний шаблонный классификатор. Наличие файла модели не включает её автоматически: менять конфигурацию можно только после успешной независимой проверки и живого сравнения. Модель с проваленными критериями остаётся выключенной.

Обе области используют нормализацию яркости, HOG и уменьшенное нормализованное изображение. Определённое положение требует согласия двух классификаторов и достаточного отрыва от других классов. Для «Открыто» область опоры должна положительно распознать поднятую стрелу. Отсутствие горизонтальной стрелы само по себе не означает «Открыто». Движение, плохая видимость, потеря свежих кадров и зависание изображения сбрасывают подтверждение; положение подтверждается тремя новыми кадрами. Диагностика в `status.json` содержит версию модели, отрыв SVM, оценки областей и причину неопределённости; отрыв не является вероятностью.

## Обучение и независимая проверка

Обучение запускается отдельно от записи и рабочего распознавателя, в контейнере без сети и GPU с ограничениями CPU и памяти. Для обучения нужны OpenCV, NumPy и scikit-learn; рабочему распознавателю scikit-learn не требуется.

Манифест содержит `origin: [x, y]` — начало сохранённого кадрированного изображения — и `samples`. У каждого примера есть относительный `path`, `label` (0/1/2), `role` (`train`, `validation`, `test`), `period` (`day`, `night`) и `group` (эпизод). Весь эпизод относится только к одной выборке. Кадры с поднятой стрелой размечаются по видимому положительному признаку; заслонение и неразличимое положение получают 0.

```sh
python -m ocr.frigate_barrier_train --manifest /data/labels.json --config /data/calibration.json --output /data/model.json --version 1.0.0
python -m ocr.frigate_barrier_train --manifest /data/labels.json --config /data/calibration.json --model /data/model.json --output /data/evaluation.json
```

Команда обучения читает изображения только из `train` и `validation`; пороги выбираются только на `validation`. Команда проверки не изменяет модель и возвращает код 2 при провале критериев: минимум 500 кадров, вдвое меньше неопределённых различимых положений отдельно днём и ночью и ни одного ложного определённого положения. После просмотра независимой проверки её данные нельзя использовать для настройки той же заявленной модели. Перед включением дополнительно проверяются движение, заслонение, сдвиг камеры, зависание, потеря кадров и живое наблюдение с нагрузкой на запись.
